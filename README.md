# goyang_dashboard

고양시 가좌·송포 고령자 의료접근성 — 똑버스 운행 대시보드.

```
streamlit run streamlit_app.py
```

| 파일 | 내용 |
| --- | --- |
| `streamlit_app.py` | 화면 |
| `sim.py` | 운행 모형 · 도로망 길찾기 · 탄소 수지 |
| `data/v6_graph.npz` | 국가표준노드링크(2025-05-12)에서 자른 고양 일대 도로망 — 노드 24,305 · 링크 35,749 |
| `data/data.json` | 접근성 분석 결과 (고령인구 · 격자 점수 · 의료기관 · 동 경계) |

가좌·송포에는 아직 똑버스가 없다. 이 화면의 운행은 광교 똑버스 실측 지표로 만든 **가상 운행**이며 고양시의 실제 운행이 아니다.
